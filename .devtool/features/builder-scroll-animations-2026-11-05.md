# Анимации появления при прокрутке

Пакет 6. Как у Tilda и Webflow, но с обзором всех анимаций страницы (их отсутствие критикуют у обоих).

## Задумка

- Любому элементу или секции можно задать появление: тип (fade, сдвиг снизу/сверху/слева/справа, увеличение), длительность, задержка, однократно или каждый раз.
- Для контейнера — «по очереди» (stagger): дети появляются друг за другом с шагом.
- Разметка — data-атрибуты; CSS и маленький скрипт на IntersectionObserver попадают в выгрузку только если на сайте есть анимации.
- `prefers-reduced-motion: reduce` — элементы показываются сразу, без движения. Без JS контент тоже виден.
- На холсте анимации не мешают редактированию; есть кнопка «Проиграть», чтобы посмотреть; в предпросмотре работают как на сайте.
- Обзор: список всех анимаций страницы с переходом к элементу.

## Проверка

Проверено в браузере (05.11): настройки у закрытой секции, на странице сайта секция проявляется при прокрутке, после показа `data-reveal` снимается.

Поправлено при проверке: `site.js` подключён с `defer`, поэтому элементы первого экрана мелькали (видно → скрыто → проявление). Теперь класс `reveal-js` ставит маленький скрипт в `<head>` (`REVEAL_HEAD_SCRIPT`), а если `site.js` не запустился за 3 секунды, всё показывается обратно. Дети контейнера «по очереди» тоже скрыты до запуска скрипта. Тест в `export.test.ts`.
