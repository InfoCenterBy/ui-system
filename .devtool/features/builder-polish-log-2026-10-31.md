# Доработки конструктора

Лог мелких доработок после проверки. Формат записи: проблема → решение, с датой и отметкой о готовности.

## Лог

### 1. Футер и хедер (31.10.2026)

- [x] **Проблема:** футер свободно плавает — на короткой странице он стоит сразу под контентом, а не внизу окна.
      **Решение:** по умолчанию футер прижат к низу (тело страницы — колонка во всю высоту окна, контент в `<main>` растягивается). В настройках сайта переключатель «Footer sticks to the bottom», можно отключить.
- [x] **Проблема:** у хедера нет настроек поведения при прокрутке.
      **Решение:** в настройках сайта выбор положения хедера: Static (обычный), Sticky (остаётся сверху при прокрутке), Fixed (поверх контента, для прозрачного хедера над hero), Hide on scroll (прячется при прокрутке вниз, появляется при прокрутке вверх, через `site.js`). Работает на холсте и в выгрузке.

      **Сделано:** настройки в Site settings → General (`layout` в `Site`, по умолчанию хедер Static и футер прижат, старые проекты тоже). В выгрузке `<body class="flex min-h-dvh flex-col">`, секции в `<main class="grow">`; классы хедера добавляются при отрисовке и выгрузке, сохранённый хедер не меняется. Скрипт Hide on scroll только на страницах с таким хедером, учитывает `prefers-reduced-motion`. На холсте Hide on scroll ведёт себя как Sticky. Проверено в браузере на холсте и в выгруженном сайте.
      **Учесть:** хедер без фона (`bg-*`) в режимах Sticky, Fixed и Hide on scroll будет прозрачным поверх контента.

### 2. Замечания после проверки (31.10.2026)

- [ ] **Проблема:** Hide on scroll у хедера на холсте не прячется (в редакторе он нарочно вёл себя как Sticky).
      **Решение:** на холсте хедер тоже прячется при прокрутке вниз и появляется при прокрутке вверх, как на сайте; если выделен хедер или что-то в нём — не прячется.
- [ ] **Проблема:** настройки положения хедера и футера лежат в настройках сайта, их не найти.
      **Решение:** перенести в правую панель: при выделении хедера — «Position» (Static, Sticky, Fixed, Hide on scroll), при выделении футера — «Stick to the bottom». Из Site settings убрать.
- [ ] **Проблема:** в режиме компонента нельзя удалить элемент внутри компонента.
      **Решение:** кнопка Delete в правой панели и в меню строки Layers для любого элемента мастера, кроме корня; проверить клавишу Delete.
- [ ] **Проблема:** непонятно, куда класть элементы, если на странице нет пустого блока.
      **Решение:** во вкладке Elements кнопка «Add empty block» (добавляет Custom block после выделенной секции и выделяет его контейнер); элемент, брошенный на холст между секциями, сам создаёт Custom block с этим элементом внутри.
- [ ] **Проблема:** непонятно, что делает Create component.
      **Решение:** переименовать в «Save as component» и добавить пояснение: блок можно вставлять на другие страницы, правки компонента меняют все копии, в копиях меняются только тексты, картинки и ссылки.
- [ ] **Проблема:** элементы в раскладках (Row, Stack, Grid, Box) нельзя перетаскивать по холсту — только за ярлык выделения.
      **Решение:** выделенный элемент тащится прямо мышью по холсту (порог 5 px, не во время правки текста), линия вставки по направлению раскладки.
- [ ] **Проблема:** стили, заданные на ширине xl, пишутся как `xl:…` и не действуют на маленьких экранах.
      **Решение:** по умолчанию стили пишутся для всех экранов (без префикса). В шапке панели стилей выбор «All screens / From md / From lg / From xl»; брейкпоинт — только когда выбран явно.
- [ ] **Проблема:** интерфейс только на английском.
      **Решение:** переключатель языка интерфейса en/ru в верхней панели, выбор запоминается; все строки интерфейса через словарь.
- [ ] **Проблема:** при раскрытии категории в Sections превью мерцает и на секунду становится слишком высоким.
      **Решение:** у превью фиксированная высота и заглушка до загрузки, без скачка.
