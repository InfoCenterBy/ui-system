# 12-колоночная система, display по экранам, xs/sm в шапке

Колоночная вёрстка по принципу Bootstrap (row + col-md-6) поверх Tailwind: родитель `grid grid-cols-12`, элементы `col-span-*` и `col-start-*` с префиксами экранов.

## Сделано

- Пресет «12-колоночная система» в быстрых раскладках сетки: n равных колонок превращаются в `col-span-(12/n)`, вид не меняется.
- Вариант Grid «12-column row» во вкладке «Элементы».
- У родителя-ряда таблица «Элементов в ряд по экранам» (xs, sm, md, lg, xl): 1, 2, 3, 4, 6 или 12, как row-cols. Одним шагом отмены.
- У элемента внутри ряда группа «Колонки»: ширина и отступ по экранам, полоска из 12 ячеек для текущего экрана.
- В «Макете» вместо «Видимость: телефон/планшет/компьютер» таблица «Display по экранам»: свой display на xs, sm, md, lg, xl, пустая ячейка показывает унаследованное значение.
- Шапка: кнопки xs 375, sm 640, md 768, lg 1024, xl 1280. 375 меньше порога sm (640), поэтому оно названо xs, а sm показывает настоящий порог.
- Общий компонент `ScreenTable`, хелперы в `style/screens.ts`, математика в `gridMath.ts` (`isColumnRow`, `perRowAt`, `withPerRow`), тесты.

## Проверка

- [ ] Сетка → «12-колоночная система», затем «в ряд» md = 2, lg = 4, переключать ширину холста.
- [ ] Элемент ряда: ширина 6 и отступ 3 на lg.
- [ ] Display по экранам: скрыть на md, показать на lg.
- [ ] Кнопки xs/sm в шапке.

## Ограничения

- Нет аналога `.col` без числа (равная доля автоматически): в CSS grid ширина задаётся числом колонок.
- Таблицы не показываются в состояниях (наведение и т. п.).

## Доработки после проверки (05.11)

- Колоночная система работает с любым числом колонок, не только с 12. Группа «Колонки» у элемента появляется в любой сетке; ширина и отступ на каждом экране ограничены числом колонок родителя на этом экране.
- В «Сетке» таблица «По экранам»: «Колонки» (1–12) и «В ряд» (1–12) для xs, sm, md, lg, xl. Отдельная строка «Колонки» убрана, её заменила таблица.
- «В ряд» n: если n делит число колонок, элементы получают ширину колонки/n; если нет, на этом экране сетка переключается на n колонок.
- Исправлено: `col-span-*` в Tailwind задаёт `grid-column` целиком и стирал отступ, унаследованный с меньшего экрана. Теперь отступ повторяется рядом с шириной (`pinStarts`), в том числе при перетаскивании на холсте.
