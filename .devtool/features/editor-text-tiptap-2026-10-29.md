# Правка текста через Tiptap

Двойной клик по тексту открывает правку прямо на холсте, набор оформления зависит от типа места.

## Критерии готовности

- [ ] Простой текст для заголовков
- [ ] Жирный, курсив, ссылка, списки для абзацев
- [ ] Чистый HTML на выходе
