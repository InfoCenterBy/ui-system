# Разблокировка секции и действия со структурой

Секцию можно разблокировать и править как дерево: выделять любой элемент, добавлять, переносить, удалять. Логика классов по ширинам экрана в ядре.

## Критерии готовности

- [x] Кнопка Unlock / Lock у секции
- [x] В разблокированной секции выделяется любой элемент
- [x] Двойной клик правит текст любого текстового элемента
- [x] Действия: вставить элемент, перенести, копировать, удалить, обернуть
- [x] Функции чтения и замены классов по ширине экрана в packages/core с тестами
