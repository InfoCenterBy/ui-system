# Компоненты с подменой содержимого, как в Webflow

Группу элементов можно сохранить как компонент и вставлять на любую страницу. Структура и стили берутся из компонента, а тексты, картинки и ссылки можно менять у каждого экземпляра.

Делаем после Webflow-режима (разблокировка секций). В MVP общими будут только шапка и футер.

## Критерии готовности

- [x] Выделенное поддерево превращается в компонент
- [x] Панель библиотеки компонентов, экземпляр перетаскивается на холст
- [x] Правка компонента меняет все экземпляры
- [x] У экземпляра можно подменить текст, картинку и ссылку и вернуть значение из компонента
- [x] Экземпляр можно отвязать и превратить в обычные элементы
- [x] При выгрузке экземпляры превращаются в обычный HTML

## Устройство (30.10.2026)

- Компонент: `{ id, name, root }`, файл `components/<id>.json` в папке проекта, в документе `doc.components`.
- Экземпляр лежит в странице как развёрнутая копия мастера: у корня метка `instance: { component }`, у каждого узла `ref` с id узла мастера. Холст, правка и выгрузка работают с обычным деревом.
- Содержимое, которое можно подменить: дети текстовых элементов, `src` и `alt` у картинки, `href`, `target` и `rel` у ссылки. Подмена неявная: содержимое экземпляра отличается от мастера. «Вернуть из компонента» копирует значение мастера.
- Правка мастера идёт в режиме компонента: на холсте только мастер, он редактируется как разблокированная секция. После каждой правки все экземпляры пересобираются: неподменённые места берут новое значение мастера, подменённые остаются.
- Внутри экземпляра структура закрыта, как в заблокированной секции. Повторы в экземпляре не добавляются, вложенные экземпляры в мастере в первой версии запрещены.
- Компонент можно сделать из элемента внутри разблокированной секции или из целой секции.

## Где остановились (30.10.2026)

Ветка `feat/builder-core`, всё закоммичено. Компоненты работают целиком, проверено в браузере.

Что есть:
- Компонент делается кнопкой «Create component» в свойствах (из секции или элемента разблокированной секции) или из меню строки в Layers. Из общей шапки и футера компоненты не делаются.
- Вкладка Components: миниатюры секций, клик вставляет экземпляр, секцию-компонент можно перетащить на холст, переименование и удаление (экземпляры при удалении становятся обычными элементами).
- Внутри экземпляра правятся только тексты, картинки и ссылки. Подменённое место помечено «Overridden · Reset», у экземпляра есть счётчик подмен и «Reset all» одним шагом отмены.
- Режим компонента: фиолетовая полоса «Editing component … — changes apply to N instances», на холсте только мастер, он правится как разблокированная секция. Выход по Done или Escape.
- Сохранение в `components/<id>.json`, при открытии проекта экземпляры пересобираются. В выгрузке чистый HTML.
- Вкладки слева со значками: на узкой панели подпись есть только у открытой.

Проверки: typecheck чистый, lint 0 ошибок и 1 предупреждение (каталог), 564 теста, format check чистый.

Мелочи на потом:
- [ ] Элемент-компонент нельзя перетащить на холст, только вставить кликом (холст принимает перетаскивание лишь между секциями)
- [ ] В режиме компонента без выделения правая панель показывает страницу, а не компонент
- [ ] У экземпляра-элемента в свойствах нет кнопок Up, Down, Duplicate, Delete (клавиша Delete и меню строки работают)
