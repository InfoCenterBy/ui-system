# Кастомный блок, этап 1: компоненты daisyUI и вставка

Секция, в которую можно положить любые компоненты daisyUI в любом порядке и сочетать их. План согласован опросом 31.10.2026.

## Решения

- Источник один: библиотека каталога `packages/blocks/src/library` (68 компонентов). Каталог и конструктор показывают одно и то же.
- Для конструктора у вариантов есть метаданные: можно ли вставлять, метка слоя, при необходимости свой «чистый» HTML без витринных обёрток.
- Компоненты со скриптами и связками (calendar, countdown, dropdown, megamenu, modal) пока скрыты, это этап 3.
- «Custom block» — новая секция: пустая разблокированная секция с контейнером `max-w-6xl` и отступами как у остальных. Пока блок пуст, в редакторе видна заглушка «Перетащите элемент сюда», в выгрузку она не попадает.
- Компоненты можно класть и в любую другую разблокированную секцию, механизм один.
- Вставленный компонент — обычные элементы: всё выделяется и правится, тексты правятся двойным кликом. Для защиты структуры и повторного использования есть компоненты с подменой.
- Раскладки: Row (`flex flex-wrap gap-4`), Stack (`flex flex-col gap-4`), Grid 2/3/4 (`grid grid-cols-1 md:grid-cols-N gap-6`), Box (пустой `div`).

## Критерии готовности

- [x] Метаданные для всех компонентов без скриптов: автоматическая заготовка (метка, замена картинок, id), ручная правка исключений
- [x] Метка слоя по имени компонента («Card», а не «div»)
- [x] При вставке переписываются id и `name` радиокнопок: две копии tabs или accordion не мешают друг другу
- [x] Картинки с `img.daisyui.com` (75 мест) заменяются локальной заглушкой проекта
- [x] Вкладка «Elements» в левой панели: сворачиваемые категории каталога, поиск
- [x] Строка компонента раскрывается в варианты с превью
- [x] Категория «Structure» с раскладками Row, Stack, Grid 2/3/4, Box
- [x] Секция «Custom block» в списке секций, заглушка пустого блока только в редакторе
- [x] Вставка кликом: после выделенного элемента или внутрь выделенного контейнера
- [x] Перетаскивание из вкладки в дерево Layers (до, внутрь, после)
- [x] В заблокированную секцию вставить нельзя, подсказка «Unlock the section to add elements»
- [x] Выгрузка: классы вставленных компонентов попадают в CSS сайта
- [x] Undo отменяет вставку одним шагом
