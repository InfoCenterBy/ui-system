# Свои токены поверх темы daisyUI

Пакет 6. Переменные сайта, которые становятся обычными классами Tailwind.

## Задумка

- В настройках сайта вкладка «Токены»: цвета, отступы, радиусы, размеры шрифта, ширины контейнера. Имя + значение.
- Токены попадают в Tailwind 4 через `@theme` (`--color-brand` → `bg-brand`, `text-brand`; `--spacing-section` → `py-section`), и на холсте, и в выгрузке.
- Цвет токена может ссылаться на цвет темы daisyUI, тогда он меняется вместе с темой.
- Токены видны в панели стилей рядом со значениями темы и в подсказках поля классов.
- Переименование токена обновляет классы на страницах; удаление используемого токена предупреждает.

## Чек-лист

- [x] Модель и проверка на сервере
  - **Сделано:** `site.tokens` (`DesignToken`: name, type, value) и вся логика в `packages/core/src/tokens.ts`: имена kebab-case, не больше 32 символов, без имён Tailwind и daisyUI, уникальные среди всех типов; значения проверяются по типу. Сервер проверяет в `assertSite` и в `/api/css`. Тесты в core и `server/tokens.test.ts`.
- [x] Вкладка «Токены» в настройках сайта
  - **Сделано:** `TokenSettings.tsx`: форма добавления, список с именем, значением, образцом (цвет, отрезок, радиус, «Aa»), примером класса и счётчиком использований. Цвет: пипетка, список цветов темы (`var(--color-primary)`) или свой цвет любого формата. Высота диалога не менялась.
- [x] CSS на холсте и в выгрузке
  - **Сделано:** Токены попадают в исходник Tailwind как `@theme`, а ссылки на цвета темы как `@theme inline`, так что `bg-soft` даёт `var(--color-primary)` и следует теме. Компилятор холста кешируется по теме и токенам. Холст, превью и выгрузка передают `site.tokens`. Попадают только используемые классы.
- [x] Панель стилей и подсказки классов
  - **Сделано:** Цвета токенов стоят рядом с цветами темы, отступы, радиусы, размеры шрифта и максимальная ширина идут в списки значений (`ValueInput`, радиус), подсказки и подсветка в поле классов через `withTokens`.
- [x] Переименование и удаление
  - **Сделано:** `store/tokenActions.ts`: переименование меняет классы на всех страницах, в шапке, подвале и компонентах за один шаг отмены (с префиксами, `/50`, `!`, минусом, `@имя:` для контейнера). Удаление используемого токена спрашивает подтверждение со списком мест.
