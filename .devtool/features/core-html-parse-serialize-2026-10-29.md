# Разбор HTML в дерево и обратно

Секция-заготовка из HTML с `data-edit` и `data-repeat` превращается в дерево, дерево выводится в чистый HTML.

## Критерии готовности

- [x] Разбор и вывод без потерь, тесты на круговой проход
- [x] Служебные атрибуты не попадают в выгрузку
- [x] Формат описания секции: имя, категория, варианты
