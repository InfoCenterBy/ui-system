# Варианты и свойства компонентов

Пакет 6. Как в Framer: у компонента несколько вариантов вида, экземпляр выбирает свой.

## Задумка

- У компонента есть основной вид и именованные варианты («Тёмная», «Компактная»). Вариант хранит только отличия классов от основного вида, по узлам компонента.
- В режиме редактирования компонента переключатель вариантов: правка стилей в варианте пишет отличие, а не меняет основной вид.
- Экземпляр выбирает вариант в правой панели; подмены текста, картинок и ссылок экземпляра продолжают работать.
- Свойства компонента: подписанные поля экземпляра (текст, картинка, ссылка, видимость элемента) вместо безымянных подмен.
- Выгрузка и холст собирают экземпляр из основного вида, варианта и подмен.

## Чек-лист

- [x] Модель вариантов в core и тесты
  - **Сделано:** `ComponentVariant { id, name, diffs }`, diff по id узла мастера `{ add, remove }` (токены классов). `applyClassDiff` вытесняет токены базы той же группы утилит и брейкпоинта, поэтому правки базы доходят до варианта там, где он не переопределял. `resolveInstance` (база + вариант + скрытые + подмены) в `packages/core/src/variants.ts` и `components.ts`, 22 новых теста.
- [x] Редактирование вариантов в режиме компонента
  - **Сделано:** Полоса `VariantBar` под баннером: Основной, варианты, добавить, переименовать, дублировать, удалить. Правки классов идут через `setClasses`, который при активном варианте пишет diff (`setVariantClasses`); холст берёт `applyVariant` в `useRoots`, StylePanel не менялся.
- [x] Выбор варианта у экземпляра
  - **Сделано:** Список «Вариант» в `InstanceProperties`, `setInstanceVariant` пересобирает экземпляр с теми же id и подменами. Удаление варианта спрашивает подтверждение со списком страниц, экземпляры возвращаются к основному виду, отмена работает.
- [x] Свойства компонента в панели экземпляра
  - **Сделано:** Свойства `Component.props` (текст, картинка, ссылка, видимость): `PropControls` в режиме компонента, подписанные поля сверху в панели экземпляра, переключатель видимости прячет узел (`instance.hidden`). Старые проекты без свойств показываются как раньше.
- [x] Выгрузка и холст
  - **Сделано:** Экземпляры лежат в странице уже собранными через `resolveInstance` (в том числе при загрузке на сервере `syncAll`), поэтому холст и выгрузка берут один результат. Валидация новых полей в `server/validate.ts` + тест.

## Проверка

Проверено в браузере (05.11): «Сохранить как компонент», в режиме компонента полоса вариантов, правка классов в «Вариант 1» пишется в вариант (основной вид не меняется), подзаголовок сделан свойством «Текст»; у экземпляра выбор варианта и поле свойства работают.
