# Доработка панели стилей и поля классов

Замечания после пробы панели стилей.

## Критерии готовности

- [x] Образцы цветов показывают цвета темы сайта (сейчас пустые, если тема без своих переменных)
- [x] При наведении на образец видно название цвета и его значение
- [x] Свой цвет: выбор любого цвета, класс вида `bg-[#1e90ff]`
- [x] Отступы (padding, margin): свой выпадающий список рядом с полем, все варианты при каждом открытии, значение применяется сразу при выборе
- [x] Свой отступ в px и rem, класс вида `p-[10px]`, `m-[1.5rem]`
- [x] Правка класса двойным кликом: клик внутри поля не закрывает правку, выход по Enter или клику вне поля
- [x] При наведении на класс в поле классов показываются его стили

## Причины (30.10.2026)

- Цвета: `useTokenColor` в `editor/style/controls.tsx` берёт цвет из `site.theme.vars`, где лежат только изменённые переменные. Иначе подставляется `var(--color-…)`, которой нет в интерфейсе редактора, и образец прозрачный. Полные переменные даёт `themeFromSite` из `store/themeActions.ts`.
- Отступы: поле — `<input list>` с нативным `<datalist>`. Браузер сам располагает список и фильтрует его по введённому тексту, а значение применяется только по `onBlur`.

## Итог (31.10.2026)

- Образцы берут полные переменные темы через `useSiteThemeVars` (`editor/style/useSiteThemeVars.ts`), в том числе в поле классов. При наведении подсказка: «primary · oklch(…)».
- Свой цвет: пипетка и поле для hex после образцов, класс `text-[#1e90ff]` или `bg-[#1e90ff]`. Прозрачность есть только у цветов темы.
- Отступы: свой список в Popover (`components/ui/popover.tsx`) под полем, через портал, поэтому его не обрезает прокрутка панели. Все варианты при открытии, фильтр только пока вводишь новый текст, стрелки, Enter, Escape. Выбор применяется сразу. Свои значения: `10px`, `1.5rem`, `-8px` там, где можно отрицательные.
- Правка класса заканчивается по Enter, Escape (отмена) или нажатию мыши вне поля. Раньше правку обрывал обработчик клика у обёртки поля.
- Наведение на класс через полсекунды показывает его CSS.
- Проверено в браузере в светлой и тёмной теме, в том числе в режиме компонента.

Проверки: typecheck чистый, lint 0 ошибок и 1 предупреждение (каталог), все тесты проходят, format check чистый.

Мелочи на потом:
- [ ] Tab при правке класса не сохраняет правку
- [ ] Цвет не в hex (например `bg-[rgb(…)]`) показывается только текстом класса
